📌 What is a Relational Database?

A relational database stores data in tables. Each table contains rows and columns, and relationships can connect tables together.

  • Tables contain data.
  • Rows represent records.
  • Columns represent attributes.
  • Keys connect related information.
📌 Primary Key

A primary key uniquely identifies each record inside a table.

CREATE TABLE students ( id INTEGER PRIMARY KEY, name TEXT, age INTEGER );
📌 Foreign Key

A foreign key creates a relationship between records in different tables.

CREATE TABLE courses ( id INTEGER PRIMARY KEY, student_id INTEGER, name TEXT, FOREIGN KEY (student_id) REFERENCES students(id) );
📌 WHERE Clause

WHERE allows you to filter records based on a condition.

SELECT * FROM students WHERE age >= 18;
📌 ORDER BY

ORDER BY sorts the returned results.

SELECT * FROM students ORDER BY age DESC;
📌 GROUP BY

GROUP BY groups records that share a particular value. It is commonly used with aggregate functions.

SELECT department, COUNT(*) FROM students GROUP BY department;
📌 JOIN

JOIN allows you to combine information from multiple related tables.

SELECT students.name, courses.name FROM students JOIN courses ON students.id = courses.student_id;
📌 Database Normalization

Normalization is a process used to organize data and reduce unnecessary duplication.

  • Reduce duplicate information.
  • Improve data consistency.
  • Make relationships clearer.
  • Reduce update problems.
📌 Indexes

An index can help a database find information more efficiently, especially when working with large amounts of data.

CREATE INDEX idx_student_name ON students(name);
📌 Transactions

A transaction groups database operations into a logical unit of work.

  • COMMIT
  • ROLLBACK
