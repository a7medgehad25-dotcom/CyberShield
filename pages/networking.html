What is a Computer Network?

A computer network is a group of connected devices that can communicate and exchange information.

Networks can range from small home networks to massive global networks such as the Internet.

What is an IP Address?

An IP address identifies a device or network interface within an IP network. 

IPv4 example:

192.168.1.10

Private IPv4 addresses are commonly used inside local networks.

IPv4 vs IPv6

IPv4 uses 32-bit addresses, while IPv6 uses 128-bit addresses. 

IPv4:
192.168.1.10

IPv6:
2001:db8::1
MAC Address

A MAC address is associated with a network interface and is used for communication at the data-link layer.

It is commonly represented as a sequence of hexadecimal values. 

Example:

00:1A:2B:3C:4D:5E
Router vs Switch

A switch commonly connects devices within a local network, while a router connects different networks.

Both are important components in modern networks, but they perform different roles.

DNS

DNS stands for Domain Name System.

It helps translate human-readable domain names into IP addresses used by networked systems. 

example.com
        ↓
     DNS
        ↓
IP address
DHCP

DHCP allows devices to obtain network configuration automatically.

This can include an IP address, subnet information, default gateway and DNS server information.

TCP vs UDP

TCP provides connection-oriented communication with mechanisms for reliable delivery.

UDP is connectionless and has lower protocol overhead, making it useful for applications where low latency is important.

Ports

Ports help identify network services associated with applications on a host. 

Examples:

HTTP  → 80
HTTPS → 443
DNS   → 53
SSH   → 22
Subnetting

Subnetting divides an IP network into smaller logical networks.

It can help organize networks and manage address allocation.

Important Network Protocols

Protocols define how network communication works.

HTTP / HTTPS

Used for communication between web clients and web servers.

DNS

Resolves domain names to IP addresses.

DHCP

Provides network configuration to clients.

SSH

Provides secure remote access to systems.

FTP

A protocol designed for transferring files.

SMTP

Used for sending email between mail systems.
